# v1.1 — planned features

Rough list, still collecting ideas.

- **Mark filtered comments that hide unfiltered replies.** When we collapse a comment, its whole subtree folds, so an unfiltered reply nested inside gets hidden too. Add a small marker on the collapsed stub when that happens, so it's not silently lost.
- **Filter necroposts in Recent Actions.** CF marks them with an `img[alt="Necropost"]` (hourglass icon) on the row. Add a toggle to move those into the filtered box.
